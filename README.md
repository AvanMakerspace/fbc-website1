# FBC Website Project

Build me a website for FBC here is there profile and also their logo

This is a lightweight static website built with HTML, CSS and vanilla JavaScript for deployment on Vercel.

## Static site

The public entrypoint is `index.html`, with styling in `styles.css` and interactions in `script.js`.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
